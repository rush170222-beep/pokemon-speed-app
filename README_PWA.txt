# PWA版

## 公開方法（おすすめ）
### GitHub Pages

1. GitHubで新しいRepositoryを作る
2. このフォルダの中身を全部アップロード
3. Settings → Pages
4. Branch を main にして Save
5. 数分待つ

公開URLが出ます。

## スマホでアプリ化

### iPhone
SafariでURLを開く
↓
共有ボタン
↓
「ホーム画面に追加」

### Android
ChromeでURLを開く
↓
「アプリをインストール」または
「ホーム画面に追加」
