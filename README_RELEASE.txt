# リリース用完成版

## GitHub Pages公開方法

1. GitHubで新規Repository作成
2. ZIPを解凍
3. 中身を全部アップロード
4. Settings → Pages
5. Branch を main にして Save

数分後にURLが発行されます。

## AdSense導入

index.html 内の

ca-pub-XXXXXXXXXXXXXXXX

を自分のAdSense IDに変更してください。

## ホーム画面追加

### iPhone
Safari → 共有 → ホーム画面に追加

### Android
Chrome → アプリをインストール

## 含まれているもの

- PWA
- 広告エリア
- 利用規約
- プライバシーポリシー
- 非公式ファンツール表記
